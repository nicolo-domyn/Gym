# Dependencies for the standalone nemo_skills sandbox process that
# nemo_gym/sandbox_launcher.py runs inside a Singularity container (see that module's
# docstring). This is NOT a Gym resources server or agent -- local_sandbox_server.py is a
# bare Flask app with no dependency on nemo_gym/Ray/openai/torch at all, so unlike every
# other per-actor venv in this repo, this one is built by its own small step in launch.sh,
# not through GYM_SPECS (which unconditionally force-installs ray[default]/openai/torch --
# multi-GB, CUDA-linked, and entirely unused here).

# resources_servers/reasoning_gym/requirements.txt -- bump all three together.
